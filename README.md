# Akshaya Digital Studio

A colorful, premium, responsive static website for **Akshaya Digital Studio**, a family-run photography and digital services business in Noothankal, Suryapet, Telangana.

## ✨ What's included

- Premium colorful photography + gold visual identity
- Custom inline camera/aperture logo mark
- Responsive mobile, tablet and desktop layout
- Hero section with strong call-to-action buttons
- Photography, wedding, printing and digital-service cards
- Portfolio/gallery showcase
- Family-business story section
- Why choose us section
- Direct call and WhatsApp buttons
- Email and Google Maps location link
- Social-media-ready structure for future Instagram/Facebook links
- No paid libraries or frameworks required

## 📁 Files

- `index.html` — page content and structure
- `styles.css` — all responsive styling and visual design
- `script.js` — mobile navigation and dynamic copyright year

## 🖼️ Replacing the temporary photos

The current gallery uses remote Unsplash photography as temporary showcase imagery. When the studio's real photographs are ready:

1. Create an `images/` folder in the repository.
2. Add the studio's own JPG/PNG/WebP photos.
3. In `index.html`, replace each `https://images.unsplash.com/...` URL with paths such as `images/wedding-01.jpg`.
4. Keep descriptive `alt` text for accessibility and SEO.
5. Commit and push the changes.

Recommended real-photo set:

- Studio exterior/interior
- Passport/ID photo setup
- Portrait work
- Wedding highlights
- Photo printing
- Photo frames
- Family/event photography
- Team/business owner photo

## 🚀 Run locally

No build step is needed. Open `index.html` in a browser, or use any simple static server.

Example with Python:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## 🌐 GitHub Pages

This is a plain static site and is compatible with GitHub Pages at no hosting cost.

In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
